## Sobre la charla

El segundo meetup del AWS User Group Mixtli se adentró en el mundo serverless — uno de los paradigmas más adoptados del ecosistema AWS. Lejos de ser una contradicción, "administrar servidores con serverless" resume perfectamente la propuesta: concentrarte en tu código y lógica de negocio mientras AWS gestiona la infraestructura subyacente.

Durante la sesión se revisaron los componentes clave del stack serverless en AWS: Lambda para cómputo bajo demanda, API Gateway para exposición de APIs REST y HTTP, SQS y EventBridge para desacoplamiento de servicios, y DynamoDB como base de datos nativa serverless.

Se presentaron casos de uso reales de empresas que migraron cargas de trabajo tradicionales a arquitecturas serverless, con énfasis en los patrones que funcionan bien y los antipatrones que generan costos inesperados o latencia inaceptable.

## Puntos clave

- AWS Lambda: modelo de ejecución, límites y cold starts
- Patrones de integración con API Gateway, SQS y EventBridge
- Cuándo serverless tiene sentido (y cuándo no)
- Herramientas: SAM, Serverless Framework, AWS CDK
- Monitoreo con CloudWatch y AWS X-Ray
