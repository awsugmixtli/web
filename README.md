# AWS User Group Mixtli - Sitio Web

Repositorio oficial del sitio web para la comunidad AWS User Group Mixtli. Esta plataforma sirve como punto central de encuentro para profesionales, estudiantes y entusiastas de Amazon Web Services en nuestra región.

## 🚀 Acerca del Proyecto

Este sitio web está diseñado para:
- Compartir información sobre eventos y meetups
- Proporcionar recursos de aprendizaje
- Facilitar la conexión entre miembros de la comunidad
- Mostrar proyectos y casos de éxito de la comunidad

## 🛠️ Tecnologías

- Frontend: HTML
- Estilos: Bootstrap
- CI/CD: GitHub Actions
